# 教学 2D 交互组件标准（全库推广规范）

本规范定义知识库正文内嵌 2D 交互沙盘（`src/content/wiki/*Interactive.tsx`）的统一视觉、叙事与安全降级契约。新建、修改或推广任何 2D 教学交互页前必须遵守本标准，并在真实浏览器完成桌面与移动端视觉验收。

---

## 1. 核心教学原则：先给物理直觉，再藏源码细节

1. **三秒看懂原则（减字 70%）**
   - 交互画布内每个视觉节点仅保留 **2～8 字短标签 + 图形/颜色/核心数字**。
   - 严禁将源码函数名（如 `prepare_for_fallback`）、复合布尔表达式（如 `!(service_stopped && memory_reset)`）、长括号备注直接堆进画布框体。
2. **四段式统一外壳（`WikiEduSandboxShell`）**
   - **顶部导语栏**：左侧为「模板类型徽章 + 机制名」与 **1 句大白话核心提问**（例如：“为什么把显存利用率 `u` 调高到 0.92，反而启动就 OOM？”）；右上角固定放置轻量次要按钮「查看原静态图 / 返回交互版」。
   - **单行控制栏（`.wiki-diagram-toolbar`）**：仅保留 1 行主操作控件（分步按钮 + `▶ 自动演示`，或核心滑块 + 2 个极值体验预设），避免多排按钮墙。
   - **动态视觉画布**：用平滑过渡（CSS transition / 流动连线 / 水位升降 / 轨道包裹）引导视线聚焦“刚刚哪里变了”。
   - **底部结论与折叠工程抽屉**：
     - 第一行：**状态徽章 + 1 句大白话结论 + 右侧单指标胶囊（KPI）**；
     - 第二行：默认收起的 `<details>`「查看工程与源码细节」，完整承载公式、源码符号、边界条件与真机实测注释，做到**新手不被劝退、硬核读者不丢精度**。

## 2. 两类标准交互母版（Archetypes）

向全库推广时，所有 2D 机制页统一归入以下两类母版之一，不另起野生布局：

### 母版 A：分步机制 / 指针与状态机演化型
- **适用主题**：Prefix Caching、RFork 容灾回退、PagedAttention 块分配、投机解码草稿校验、连续批处理调度等。
- **交互标配**：`▶ 自动演示`（自动步进并在末步停驻，组件卸载必清定时器）+ `‹ 上一步 / 下一步 ›` + 3～5 个编号状态钮 + 左右方向键与数字键快捷切换。
- **视觉表达**：左侧真实输入词块或主干站点轨道，中间动态连线或移动包裹，右侧物理资源池或红绿灯安全门结果卡。

### 母版 B：连续滑块 / 参数权衡跷跷板型
- **适用主题**：ACLGraph 图模式 × 显存利用率 `u`、Chunked Prefill 批预算跷跷板、KV Cache 容量账本、算力/带宽 Roofline 等。
- **交互标配**：核心模式切换钮 + 连续 `<input type="range">` 滑块 + 1～2 个一键体验极值按钮（如“稳妥 0.82” vs “试试 0.92 爆显存!”）；触发越界/告警时提供**一键应用安全处方**按钮。
- **视觉表达**：左右双因果面板对照（例如左看“速度/空泡收益”，右看“单一显存水箱代价”或“老用户丝滑度 vs 新长文首字步数”）。

## 3. 安全注册与色彩无障碍硬门禁

1. **审阅态与变更自动回退契约（`interactive-diagrams.ts`）**
   - 所有组件必须在 `INTERACTIVE_2D_REGISTRY` 中静态显式注册，绑定对应 `wiki/diagrams/<id>.svg`（LF 归一后）的精确 `approvedSvgSha256`。
   - **正式阅读态**（`allowInteractive === true` 且 SHA-256 匹配）：**默认直接展示交互态（`initialMode = "sandbox"`）**，点击右上角「查看原静态图」或按 `0` / `Escape` 可随时查看原审定 SVG。
   - **审阅态**（`ReviewPane` 等 `allowInteractive !== true`）或底层静态 SVG 发生哪怕 1 字节更新时：自动回退渲染清洗后的静态 SVG，绝不遮盖待审修改。
2. **色彩与排版约束（对齐 `DESIGN.md`）**
   - 仅使用 `src/design/tokens.css` 语义变量（暖纸底 `--color-surface`、墨色 `--color-ink`、唯一主强调 `--color-accent`、Token 青 `--color-token`、KV 靛蓝 `--color-kv`、权重琥珀 `--color-weight`、通信梅紫 `--color-comm`、告警红 `--color-danger`），禁止引入未定义的霓虹色或裸十六进制杂色。
   - 内嵌 `<svg>` 宽度 `<= 900`、字号 `>= 12px`，多实例同页渲染时 `<marker id>` 必须结合 `useId()` 隔离。
   - 窄屏（`<= 820px`）自动折叠装饰连线并转为单列纵向流式排布，零横向溢出。
