# v0.30.0rc2 全库对照补齐验收

2026-11-03。任务起点的 144 个相关页面已补齐 rc2 对照，另新增 1 个统一版本基线页，共 145 页。当前发布范围为 106 个概念页、33 个参数页和 1 个来源页，共 140 页；另 5 个参数页在草稿区保留本次对照。逐页文件路径、修改前后 SHA-256 和发布状态见 [覆盖清单](v030rc2-20261103/scope-final.json)。

## Why：为什么按固定版本逐页对照

用户选择的是所给链接的 `releases/v0.30.0rc2` 分支。本次将 Ascend 固定到 `7d825229c77025cfb185a010c25819c1214b9450`，配套上游 vLLM 固定到 `ced6857afa0ea7b2e3f0846a62e1394e90f15607`。Ascend 分支比 rc2 发布标签多两次文档提交，用户关注的 CP 设计文档没有变化；后来的 Ascend v0.30.0 正式版不纳入本次对照。基线、原始引用和阅读边界统一见 [v030rc2-baseline](../../../wiki/sources/v030rc2-baseline.md)。

任务起点共 167 页，其中 155 页带相关社区引用，144 页属于当前机制或参数说明；141 页存在引用内容改变、位置移动或旧文件消失，需要重新核对。工作量主要是逐项确认执行条件、默认值、消费者和后端限制，并补齐证据、独立复核及浏览器验收。不能由引用路径变化直接推断机制变化，也不能只替换版本号。原始统计保留在覆盖清单的 `summary` 中。

## What：完成范围与维护方式

概念页在“对照源码 → 版本差异”补充 rc2 结论及来源。参数页补充本版定义、实际消费位置、适用条件和版本谱系；23 个 rc2 中存在定义的参数更新了定义摘录，其余 15 个更新了保留、移除或历史边界说明。统一维护源增加了 rc2 pin，旧版内容与 GLM 双机部署算例继续保留原始基线。

本轮重点核对并修正的边界包括：

- [Context Parallel](../../../wiki/concepts/context-parallel.md)：区分设计文档的旧限制、实际 V2 PCP 路径、DCP，以及 GLM 的 SFA-only DSA-CP；明确 KPool 拒绝 PCP/DCP，避免把查询分工当成 KV 分片。
- [NPU Model Runner](../../../wiki/concepts/npu-model-runner.md)：核对 Ascend 对上游选择属性的覆盖。最终属性决定 V1/V2，环境变量未设置时 Ascend 使用 V1；保留 GLM 教程的 V1 要求。
- [稀疏 KV 卸载](../../../wiki/concepts/kv-cache-sparse-offload.md)与[量化](../../../wiki/concepts/kv-cache-quantization.md)：分别解释主 KV、LightningIndexer 缓存和 C8 格式，收窄融合拷贝的 int8 支持条件。
- [细粒度 TP](../../../wiki/concepts/fine-grained-tp.md)、[负载均衡](../../../wiki/concepts/balance-scheduling.md)、[KVPP](../../../wiki/concepts/kvpp.md)、[Sleep Mode](../../../wiki/concepts/sleep-mode.md)：补齐 connector、通信组、图模式、固定形状、清理失败与分阶段唤醒的实际条件。
- 清理“只有 main 才有”“钉住版本均不存在”等已被 rc2 改变的笼统措辞；仍属于旧快照的图、数字和历史记录明确保留其范围。

任务期间，另一项维护将以下 5 个参数页移入草稿区；本轮在实际草稿文件中保留了更新，没有重新发布骨架页，也没有覆盖归档副本：`runtime-config-abb228bbf148`、`runtime-config-hot-reload-9c9ab794933a`、`runtime-config-path-e23e596c2a2e`、`multistream-engram-overlap-29113aa3f8fc`、`kv-pool-range-debug-83e8b165addd`。

## Tradeoff：证据范围

本次完成的是现有相关页面的版本差异补齐，保留旧教学基线，没有把每一页的全部历史内容重新认证为 rc2。`verified` 未因增加局部对照而批量提升。审计工具仍有 357 个 URL 未联网逐条验证、1,913 条全库 raw 引用待核对；这些统计包括历史与范围外来源，行号校验通过不代表它们的内容或结论均已验证。

本轮对新增结论核对了固定版本代码和原始资料，并完成独立复核；没有 NPU 设备运行、精度或性能实测，也没有承诺所有模型和硬件组合可用。未执行全套端到端自动化或新增 3D 播放验收；当前任务的页面阅读和导航通过浏览器人工式操作验收。改动保留在本地工作区，未提交或推送。
