### 改了什么

现版（重写后）只剩约 44 行正文，丢了重写前那版（提交 `a6c8e7d`，约 122 行）的大部分内容。本轮按新讲法把丢掉的内容补回，正文结构改成：

1. 是什么——「单独重跑同一个问题，回答却分叉了」（直觉场景，先不算数）；
2. 为什么会变——浮点加法不满足结合律，float32 三个数的手算例子（a = 16,777,216、b = 1、c = −16,777,216，两种分组得 0 与 1），再说明矩阵乘为什么会按批里 token 数挑分组策略；
3. 怎么做——固定分块，一条累加链从头加到尾；softmax 拆五步、attention 换实现、跨卡求和顺序也钉死；派发表按 AscendC / Triton 两条供应链的在场情况挂实现（表格）；
4. 代价——自定义算子整层下线、归一化拆两步、采样回落、固定分块不调优；不支持项不会自动关；
5. GLM 双机——**未启用**，无实测数，只讲要开得先动哪三项、以及两处覆盖缺口；
6. 常见误解；
7. 对照源码五个 H3（怎么开 / 会报什么错 / 开销和什么时候别开 / 版本差异 / 源码位置），之后没有 H2。
