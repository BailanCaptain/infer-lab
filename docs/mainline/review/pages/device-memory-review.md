### 问题清单

**P2-1｜第 46–62 行｜页标题问题“为什么要搬”没有给出理由。** 第一个 H2 问“权重在主机里，为什么还要搬进显存？”，本节却没有回答：第一屏 L48–50 在解释矩阵、token、向量和平台契约。到第二屏 L60，理由也只是一句断言：“NPU 执行默认的本地计算路径，需要本卡显存里已有输入和权重”，没有说为什么。真正的理由是：每一步计算都要把本卡约 20.58 GiB 常驻权重整份读一遍，而设备本地显存（HBM）的带宽远高于主机到设备的链路。所以只在启动时搬一次、之后每步在本地读，才划算；也正因为如此，L107 的“注册成可访问地址”不能代替复制。**影响：** 初学者记住了“要搬”，却说不出为什么不能留在主机让 NPU 直接读，而这正是页标题的问题，也是理解卸载代价（L62）和主机注册（L107）的前提。**修法：** 在第一屏的定义之后补 1–2 句理由（每步都要整份读权重，本地带宽远高于链路带宽）。主机到设备的链路带宽底稿里没有，正文先定性描述，页末「待核」加一条，不要自己造数字。L48 对 token 和向量的解释挪到真正用到它们的 L85。

**P3-1｜L62｜“每层几次”写得别扭。** 原句“它没有‘每层每个 token 都从主机搬一次’的固定次数”读起来别扭，而标准要求第二屏讲清“每层几次”。建议直说：启动时每卡搬一次（约 20.58 GiB，整个实例共 16 份），之后每个 token 0 次；只有启用卸载的数据才会再搬。
