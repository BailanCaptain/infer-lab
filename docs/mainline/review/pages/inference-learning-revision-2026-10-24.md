## 变式问题检验

独立审查者只依据本轮正文回答了以下问题，均能指出证据位置与成立条件：

| 变式 | 页面提供的判断 |
| --- | --- |
| B 在 500 ms 算完，650 ms 才收到 | 补执行后处理、发送、代理与接收记录，先核请求关联及时间基准 |
| 总吞吐不变，B 多两条达标但还有失败 | 只能说明本窗口达标交付更多；成功率、未完成、分组退化及波动尚须验收 |
| 本卡通信长，别卡到 600 ms 才就绪 | 先看迟到卡的工作与依赖，不能直接认定网络慢 |
| 代理收到内容而客户端没收到 | 保存响应流并按同一时序重放，对照直连/代理及缓冲配置，最后回真实服务验收 |
| 模板对齐后仍输出不同 | 查生效采样，再比较共同前缀下首次分歧的分数与状态 |
| 原始流不重复，UI 重复 | 离线重放片段验证拼接，修正后同时检查不重复、不遗漏 |
| 交接从 30 ms 变成 120 ms | 本例拆分首字为 240 ms，慢于共用的 220 ms；另测持续输出与达标吞吐 |
| 6 条/秒完成量更大为何不选 | 首字达标仅 82%，低于 95%，且队列增长；5 是展示档位的最高合格点 |
| 120 秒注册、200 秒清空后是否全达标 | 历史超时仍是事故损失；恢复后的新窗口另验 SLO 与输出 |

这不是产品问答模型的端到端评估，没有据此报告知识库问答准确率提升，也没有替代真实用户的学习反馈。
