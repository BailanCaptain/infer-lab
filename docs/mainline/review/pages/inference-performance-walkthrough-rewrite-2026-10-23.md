## 改写前判断

原稿在介绍 D、N 后，连续切换到指标词表、环境采集清单、三份记录、候选原因表，再回到案例。读者需要自行把这些材料拼回一条分析过程。“位置、窗口、口径、候选、对齐”等词过密，部分句子省略了动作的对象。原稿把实验放在 GLM 部署后，也让通用方法与具体配置来回切换。

重写顺序：D 的回答发生停顿 → 算出停顿持续多久 → 找到同一批执行 → 检验长提示词的影响 → 检查收益与代价 → 补全其他原因和现场记录 → 落到 GLM 双机 → 误解与源码。参数、数字及深入机制继续链接唯一出处。
