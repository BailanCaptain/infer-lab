# 真实站内问答：验收范围与可执行步骤

本批通过读者站点的真实问答接口测试六道未测问题。主要发现不是缺少教学知识，而是回答有时把已有结果重新列为待验项，或把条件性补测在结论里变成必做门槛。修订集中在手册的三条共用查询规则，没有新增教学页，没有改写概念正文、应用代码或图。

六题共完成 **12 次 HTTP 调用**：四次首答、两次第一版回归、两次第二版回归、两道留出题首次作答，以及最后两次定向收尾。另有一次读取快照时遇到并行写入，发生在发送 HTTP 之前；没有生成答案，单独保留。所有初答、失败判断和回归都保存，不将重跑充作新题。

按各题最后的独立复核，六题的必要判断、相关验收与可执行步骤均满足本批要求；最后两份收尾无遗留 P1/P2。这是跨修订的逐题结果，不是六题在同一最终规则下的一次通过率。

## 六题怎样考，知识库帮在什么地方

题目由独立 agent 核对历史题集后设计。新颖性指新的决策条件，不声称停止、缓存或重试这些概念从未测过。题干均明确是合成记录；真实运行的是站内问答，不是题设里的设备实验。

| --- | --- | --- |
| [P1：换行停止造成漏项](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/runs/P1-final/answer.md) | 已有 22 份漏项足以拒绝设置；撤销新增停止串，以漏项样本核机制、同批表格核恢复 | 完整交付全部待处理项目，再使用原耗时目标比较；不为否决设置另做容量或设备验收 |

## 首答的问题与修订

独立评分者先核题意与冻结依据，随后逐题读原答及当次引用正文。没有把自动 `covered` 当作通过。

- **P3 首答追加启动门槛。** 已成功启动且 align 模式确认，当前缺的是新配置的长历史验证；回答却再次要求启动成功、准备耗时和启动峰值，并放入保留条件。它让已证实的前提变成额外工作。
- **P4 首答增加题外门槛。** 当前只缺可见答案的计时，回答却追加峰值内存、吞吐与未定义的资源退化门槛，足够的既有记录也无法让决定结束。
- **P4 第二版回归仍有首尾矛盾。** 开头允许已有记录够用就不重跑，结尾又要求重复证明 CPU 收益。第一版该题通过也不能覆盖这次失败；原答和独立判断分别保留，继续修正条件在结论中的表达。
- **P1 首答存在非必要展开。** 拒绝停止设置已有充分证据，后面的全面资源与重复对照偏宽。最终收尾答案先否决候选、只复核受影响的输出完整性与原耗时要求。

另有一项**评分范围纠正**：P2 初评按冻结条目要求重复序列后不净累积，但题目只问单个 R 的超时重试收尾，没有要求证明长期无泄漏或采用新策略。原答已说明该尝试的终态、引用及记录清理；反复验证应是怀疑持续残留或修改策略时的条件项。保留原初评，在[评分歧义说明](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/private/criterion-ambiguity-review.md)单列校准，不把改分当作产品修复。首轮原始判定 1/4 通过，题意校准后 2/4 通过。

修订只落在 [HANDBOOK 查询规则](../../../../wiki/HANDBOOK.md#查询)：先给最小动作、取证与判读；已足够否定候选就收束；只补尚缺且影响当前决定的验收；已证实结果直接沿用；结论不能把条件性补测变成无条件门槛。保留必要质量、延迟、成功/失败/未完成、资源、版本与证据约束。最终查询片 **1433 字符，比本轮修改前少 1 字符**，没有靠追加长清单解决问题。

静态复审保留全部初审意见并逐项关闭，见[规则复核](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/private/rule-review.md)。原初评、两版回归、留出首次答案与最终收尾分别保存在 [initial-review](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/private/initial-review.md)、[regression-review](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/private/regression-review.md)、[holdout-review](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/private/holdout-review.md)和 [closure-review](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/private/closure-review.md)。不能把此前通过与失败的生成混为一次稳定成绩，也不能用回归的最终选择宣称总体通过率。

## 调用证据与限制

请求从 `http://127.0.0.1:5173/api/wiki/chat` 经现有前端代理进入同一产品服务。每次使用新会话，提交的 JSON 只有原问题，不附指定页、评分条件、答案或额外作答提示。服务自动检索和组织回答，未新增接口或依赖。

12 次完整调用均 HTTP 200、无错误事件，有原始 SSE、正文、知识版本和引用收据。requested 模型为 `gpt-6.1-sol`，provider 为 Codex，未报告切换；不将 requested 当成已取得实际服务版本、随机种子或可复现性保证。未观察到网络工具事件，产品仍允许联网，不能称为强隔离离线试验。

为追查检索与输入，调用前用产品现有函数重建候选材料：**11 次版本与命中匹配；P1-final 的版本不匹配，不把它的预重建清单当作实际完整输入。** 该次仍有服务保存的当次引用正文。全部 12 次原答哈希与捕获答案一致；所有捕获引用页和 52 条自动审阅引文逐字核对通过，自动审阅的回答引文也均存在。引文存在不等于语义正确，最终仍采用独立全文判断。

共享工作区在调用间有其他页面更新。P3-final 的量化、Token 页与首轮版本不同，复核者已核对相关新增段落；不能把回答全部差异都归因于手册修订。H1 首次准备阶段遇到“知识库在读取时改变”，尚未发送 HTTP，另名重试后才有第一份答案。这些过程都在[调用清单](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/call-inventory.json)与[证据核对](../../../../tools/wiki-runtime/inference-product-acceptance-2026-11-01/evidence-integrity.json)保留。

两道留出题在第二版规则后首次运行并通过，最后一处条件一致性修改之后仅做 P1/P4 定向收尾。它们不是最终规则下六题各重复一次的实验，也没有统计显著性、真人学习或设备收益结论。
