### 1. 初学者测试（只读前两屏）

能说清。我的一句话：**token 是分词器把（套好聊天模板的）文本切成小单元、再查词表得到的整数编号；它和字、词不一一对应。分词是在词表大小和序列长度之间取舍；代价是入口 CPU 要套模板、做编码，主机内存要存这些编号，而 token 越多，后面设备上的计算和历史状态占用也越多。**
