# 第二轮方案：全站分组审查与整改

承接[第一轮方案](2026-11-03-wiki-remediation.md)。用户已授权连续完成两轮方案、整改与验收，不在中间等待批准。第一轮发布机制及已知缺口已修订并独立复核；第二轮以第一轮结束后的 163 页快照为对照基座。

## 工作方法

六组分别完整阅读，再记录问题、补原始证据、修订、复审和验收。已经读完的组进入整改，其他组继续审查；新问题先加入组报告再修改。全站覆盖必须最终达到清单 163/163，不能用关键词扫描或抽读取代。完整阅读与逐条引文重验分别记录，不声称全部官方站点已读完。

每处修改保留原概念主线、已认可图布局、算例及必要的旧版边界；新增功能放在明确版本的小节。全局资源数字仍从唯一出处引用。维护过程留在本目录及审查记录，学习页面只保留现行解释、可用证据和具体适用条件。

| 6 | 全站表达与发布 | 清理仍留在当前正文里的“草稿转述、归档 raw、已核第几行”等审计叙事 | 先核对应事实；真实未实测或缺失证据改写成具体边界；不直接抹掉不确定性 |

## 交付和验收

- 每组留下阅读哈希、问题编号、修订对应与复核结果。没有问题的页也进入覆盖记录。
- 对照 `.tmp/wiki-remediation-2026-11-03/phase1-pages.zip` 检查有效解释、算例、版本条件与链接去向，不用 Git HEAD 替代本轮前态。
- 运行内容检查、wiki lint、来源行号审计与图规格校验；发布代码全套测试重新跑绿。已有代码类型检查、Lint、构建结果一并保留。
- 不改已认可 3D；静态图只有事实标签错误时改最小文字并重新生成。图变更不能用规格检查冒充视觉验收。
- computer-use 已因 Windows URL 无法可靠识别停止。本轮浏览器交互阅读暂未完成；无 NPU，性能、精度和实际部署验证不在已通过项中。最终明确报告两项限制。

方案建立后，六组依次完成全文初审、证据扩读、修订与独立差异验收。已确认的 P1/P2 均已关闭；交叉复核追加的 Sinkhorn 图文、MoE 源行与专家任务、KV Pool 清盘恢复、Xlite 预算及参数批处理问题也已修订。保留原算例、旧版本条件与图布局，未重做 3D。
