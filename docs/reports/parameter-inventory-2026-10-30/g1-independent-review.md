## 参数事实与版本核对

- **Gloo/Host 网络三项**：固定 PyTorch 2.10 源码的显式列表条件为字符串长度大于 1；空串/单字符走 hostname 路径，失败可回 loopback。Gloo 接口名精确匹配，多个接口轮转、各进程数量一致。HCCL 匹配列表选首个匹配；HCCL_IF_IP 的单个 Host 地址优先于接口名。页面没有把 Gloo 语法套到 HCCL，也没有把 Host IP 写成 NPU IP。
- **HCCL_OP_EXPANSION_MODE**：使用 CANN 9.1.X 的 A2 条目，HOST 默认、AIV 配方值、通信域覆盖、无效值回默认、资源争用与图/组网边界区分正确。新增替代模式说明经复审与 A2 原文一致。
- **Worker RPC**：直接读固定 multiproc_executor.py 第 307–404 行，execute_model/sample_tokens 各传入超时；deadline 在发起时计算，future 不重新计时，execute_dummy_batch 没有传该环境值。300 是上游 getter 默认，db701c1f/2c59ff10/baa023ad 的平台改写条件严格是 `<1836`，不是 `≤1836`。2ed6cbba 的无改写结论限定已扫描运行包，不误写成上游变量消失。
- **HCCL 两种等待**：CONNECT 为 120–7200 秒、默认 120，另有 20 秒失败通知。EXEC 的 HOST/HOST_TS 与 AIV 对 0、范围和精度含义不同；配方 AIV+3600 不被写成实测 3600。通信域优先与硬件量化仍保留，未声称三层哪个必然先报错。
- **HTTP keep-alive**：三版固定 vLLM getter 都为整数秒、默认 5，普通 API/render 都传参；main 的文件迁移明确。示例讲响应结束后的空闲连接复用，不把 SSE 间隔、TTFT、总生成时限混入。0 不被解释为无限。
- **HCCL_BUFFSIZE**：官方 ≥1、默认 200、域级覆盖与 MC2 stoul 解析分别表述；配方 1024 对应每方向 1 GiB、收发预算 2 GiB，但 MC2 判据仍按单窗口。完整 tiling 文件四版同 hash 的证据支持本算子解析/判据一致，不扩大为所有 MC2 或运行时一致。原有配置合计和 KV 折算的条件仍保留。
- **两个待核变量**：重新读了固定 TensorPipe 消费者、torch_npu 后端注册/初始化分界、vLLM 未知变量校验，以及变量核查报告的完整包扫描范围。TP_SOCKET_IFNAME 在依赖确实存在，但不属于当前 mp/Gloo/HCCL 主路径；VLLM_RPC_TIMEOUT 在固定包未注册、不替代执行等待。结论没有扩展到用户另装插件，也没有把历史单位当当前有效单位。
