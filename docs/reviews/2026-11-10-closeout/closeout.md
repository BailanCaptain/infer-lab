# 既有修订收尾

范围来自本目录 plan.md：收拢中断前已实施的修订及报告中已经确认的问题，随后单独做 200 个尚无逐项判定的来源出现项。本报告不把全站未判定来源、待研究的兼容性问题或设备验证算成完成；这些仍属于后续内容审计。

## 已实施的修订

- 请求入口与执行链：修正 ID 回退、DEBUG 日志等级、Executor 类名、固定镜像日志调用、纯文本与张量输入的职责边界、零 token 协作、PP 广播和指定 rank 回传、加载回退版本、恢复请求块表替换、单步输出与 SSE 合并的区别。结构化输出的异步过滤不再宣称省掉已派发前向。关键分支与新引用经固定源码复核。
- 参数刷新：20 页自动定义恢复到 seeds 钉住的 rc2，版本谱系使用四个教学钉点。巡检新提交保留差异入队，包含仅行号迁移；不直接覆盖正式页。手动建页拒绝不匹配教学钉点的输入，带页面的谱系刷新默认也按 seeds。两个派生字段改为字段身份，不再生成可直接输入的假 JSON 路径。19 页人工正文未改，size 页另修布尔转换并补 helper 来源。
- 缓存：复核并保留 OpenCode 的 null block 扣减、align 状态保存时机、规格公式边界和启动顺序；补共享块容量前提、释放块号与覆盖旧内容的区别、waiting 首次查前缀的条件、KVPP owner 等待及旧 main 的 eager 范围。图与正文对应修订。
- 分离部署与算子：单组/多组缓存加载失败的处理分别说明；GLM 混合模型不能选择 recompute 失败策略；PD 图成功后才继续前向，截尾仅用于多于一个位置的输入。UCM 的 17,000 启动上限与 32K–128K 测试不再当作完整复现配方。稠密模型错误补 DP>1 条件；DeepSeek-R1 配置固定 revision；PR 设计说明改为 S 证据。算子登记范围、KDA 64 常量及卷积宽度补直接来源。
- 投机与量化：保留已有版本与配置条件修订；撤去仅凭 MTP 层数推断训练目标、未验证融合数学等价的断言，分清首个拒绝候选的判定输出与它自身作为输入的计算。量化直觉图的 4×6 输出已经实看。

没有覆盖其他会话的 3D 演示、CP/TP/DP 页面场景切换及 chunked-prefill-v2 样例改动。未执行提交、部署或发布。
