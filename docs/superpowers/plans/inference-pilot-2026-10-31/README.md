# 推理知识库首轮试跑包

这份材料用来检查两件事：读者能不能沿着现有文章理解一次等待，以及遇到新的报错时能不能提出有依据的下一步。首轮只安排一名学习者读前两站、一名从业者分析一个公开启动案例，先找题目、阅读安排和评分中的问题。

完整验收规则仍由[真人试读与现场排障验收方案](../2026-10-31-inference-user-field-acceptance.md)维护。本包不新增 Wiki 教学页面，也不替代后续五站阅读、延后复测、性能与恢复案例和现场实验。

从业者案例已被现有知识库收录。这次检查的是能否找到并正确使用已有依据，不把它当成未收录故障的迁移测试。试跑结束后揭示出处；正式测试另用未见题。

## 分别发给谁

| 接收者 | 发出的材料 | 暂时不发的材料 |
| --- | --- | --- |
| 学习者 | [学习者任务单](learner-task.md)，以及主持人按阶段打开的两篇现有文章 | 本说明、主持人稿、评分依据、其他人的回答 |
| 从业者 | [从业者案例](practitioner-case.md)，首次提交后再开放知识库 | 本说明、原始 issue 全文、主持人稿、评分依据、旧测试报告 |
| 主持人 | [主持人提问稿](moderator.md)，以及参与者材料 | 测试中不向参与者展示评分依据 |
| 评分与复核者 | [单独的评分依据](private/scoring.md)，以及未经改写的原答、提示记录和材料版本 | 首轮先独立评分，再讨论分歧 |

参与者文件没有链接到答案。`private` 只是分发约定，不是访问权限控制；不要把整个文件夹或整个仓库交给需要隔离答案的真人或 agent。使用仓库内 agent 时，同一文件系统仍可访问其他文件，只能约束其读取范围并保留记录，不能称为安全隔离。

## 开始前准备

1. 主持人确认读者此前是否看过这两篇文章、这个案例或评分依据；看过答案的样本只用于检查材料，不算未见题作答。
2. 固定任务单、评分表和允许阅读的页面版本。记录文件路径和 SHA-256；试跑中发现问题先记下，结束后另存修订版，不覆盖首答。
3. 真人用现有 Wiki 阅读，保留正文和原图；记录浏览器大小、实际读到的位置和点击路径。学习者只读任务单指定的主体部分，GLM 部署和源码章节留待后续。
4. 分别预留 45 分钟和 25 分钟。允许提前结束；到时仍没做完就记录停点，不把“被催着读完”记成理解。
5. 开始时说明：这次在找材料的问题，不考英文术语或参数记忆；不知道可以直说，但请留下当前判断。

原始记录放到 `tools/wiki-runtime/inference-user-field-acceptance/<批次>/`。批次至少保存：题目与资料版本、匿名参与者背景、逐阶段原答、打开资料的时刻、提示原话、初评分和复核理由。记录格式复用[原方案的四张表](../2026-10-31-inference-user-field-acceptance.md#8-可直接复制的记录表)。

## Agent 可以怎样试跑

Agent 适合检查题意是否歧义、资料能否支持答案、题目是否误导、评分是否漏掉合理答案。它还可以检查引用和算术。它无法代表初学者的阅读速度、真实困惑或延后记忆，也不能替现场操作生成日志。

本轮模拟采用新上下文：一个 agent 只拿学习者材料与两篇正文快照，另一个只拿从业者案例与指定知识库正文快照。它们不接收父会话、不读隐藏评分、不查原始 issue、不联网、不操作服务。第三个 agent 可在提交后复核题目和评分。模拟用 Markdown 快照，不检验页面图片、浏览器导航或真实阅读耗时；真人试跑仍需在网页完成。

从业者模拟先提交只看案例的判断，再查资料补交完整方案。两阶段的问题数量和时限不同，首答只记录，不与后答计算分差；可以逐条核对哪些动作得到资料支持。Agent 可能已掌握相关知识，且同一上下文存在顺序影响，不能用一次前后差异证明知识库有增益。正式有库/无库对照仍按原方案另做。

知识库材料直接复制现有页面用于冻结版本，属于测试附件，不是另一套维护的教程。现场版本变化后重新冻结，不在副本里修正文。

模拟“知识库助手怎样组织回答”时，另附由 `loadHandbook` 提取的[手册查询规则](../../../../wiki/HANDBOOK.md#查询)，与正文一同冻结并记录哈希；不要另写一套长期维护的回答指令。它只规定怎样使用材料，不包含本题评分或答案。纯学习者试读仍只给任务单和正文，不能把助手规则加给真人后称为原有阅读试验。若要测指令本身的作用，保留同题、同页、同长度要求，仅改变指令，分别保存原答；历史试跑指令不追改。

## 本包到什么程度算准备好了

每道题都能找到依据，缺少的证据有明确停点；参与者无需答案文件就能理解任务；评分能接受有依据的不同方案。Agent 若指出题目歧义，先修任务或评分，再用未读过修法的 agent 或真人检查。试跑题和本次公开案例不进入正式未见题题库。

真人试跑、延后复测、正式对照和现场验证均须各自留证据。本包准备完成或 agent 回答正确，不替这些项目勾选通过。
