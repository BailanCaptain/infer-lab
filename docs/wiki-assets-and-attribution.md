# 知识库图形、来源与复用范围

核查范围：2026-09 教学改版新增或重绘的知识库图、正文、通信演示，以及它们的本地运行依赖。本记录说明使用了什么，不替代整个仓库的发行许可审查。

## 本轮使用的资产

| 资产 | 使用方式与来源 | 仓内位置 / 条件 |
|---|---|---|
| 知识库教学图 | 按模型配置、固定实现与手算例重新编写 figure 规格，统一由本站渲染器生成 SVG | `wiki/diagrams/*.yaml` 为可编辑来源，配套 SVG 入库；不是截图外链 |
| GLM 模型图 | 参考用户已有 glm-flow 的模块连接与展开关系，再对照官方配置和专用镜像源码核查，重新编排为知识库总图/分图 | `glm-flash-*`；没有复制独立母版 HTML/JS 作为运行依赖，来源基线见对应页面 |
| NPU、板卡、服务器、机柜、交换机等轮廓 | 由本站 figure 渲染器绘制的示意轮廓 | 不使用厂商商标、产品照片或尺寸图，不据轮廓推断硬件规格 |
| 通信分步演示 | 本地 React 组件展示四类集合通信的输入、过程和结果 | `src/content/wiki/CollectiveDemo.tsx`；无外部动画资源、无自动联网请求 |
| 博客与模型图集 | 用户提供的 [Maarten Grootendorst 的 MoE 讲解](https://www.maartengrootendorst.com/blog/moe/) 与 [Sebastian Raschka 的架构图集](https://sebastianraschka.com/llm-architecture-gallery/) 用于讨论图的组织方式 | 本轮未把其中图片或页面代码复制入库；模型事实以各页列出的一手资料为准 |
| 论文与官方模型材料 | 引用机制、公式、模型配置和固定出处 | 每页 `sources` 就近关联结论；未打包模型权重，引用不意味着本项目取得权重再发行权 |
| vLLM / vllm-ascend 源码与示例 | 固定 commit/path/line 的实现依据，必要时解释短片段或命令 | 保留上游身份；原代码适用上游 Apache-2.0 条件，不能以本站未来许可覆盖 |
| RFork 工作版 | 用户提供的原补丁、完整历史衔接差异与源码快照 | `rfork/source/LICENSE`、manifest、seeds 保留；不是本轮新创作的实现 |

模型图与教学页不要求读取开发者桌面的 glm-flow 目录，也不要求启动其本地服务。文档中的本机绝对路径仅是历史开发记录；打包入口采用仓库内资源。

## 既有资产与公开前事项

- Draco 解码器已有 `public/draco/LICENSE` 和来源 README，继续保留。字体与 JavaScript 依赖由锁定的包管理依赖提供，适用各自包内许可证。
- `reference/parallelism-teaching-dark/` 是既有参考材料；本轮重绘并行图没有把这些 PNG 当作知识库运行素材。不能仅凭其位于仓库中就认定整个参考包已取得再发行许可。
- 首页城市模型与其 Blender 源是既有独立资产；本轮没有修改、重新取源或对其作完整权属判断，维护记录在 `assets/city/README.md`。
- RFork 原补丁含同事公开仓库的邮件头及署名，保留原件和校验值。按既有约定，对外发布仓库前需与同事确认；这不阻碍当前本地教学改写。
- 根目录目前没有统一项目 LICENSE。本轮不代替维护者选择许可证，也不把“计划开源”记为已获所有材料的公开发行授权。

公开发行前应明确发布范围与项目许可，逐项处理上述既有资产。当前交付是本地可审阅的内容与代码；没有推送或发布网站。

## 新资料入库时的操作

新增图或文件先记录来源、作者/组织、固定版本和使用方式，区分链接、引用、重绘和原样分发。原样分发的第三方材料保留其要求的许可证与署名；没有确认可分发的材料只保留链接与自行撰写的机制解释。新证据导致模型连接或推导变化时，同步改 figure 规格、正文及受影响依赖页，不以“重绘”替代事实核对。
