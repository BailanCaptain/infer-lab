## 排出来是什么样

每项占一行，分四栏：**标签 ｜ 算式 ｜ = ｜ 结果**。

- 多步推导的中间步骤都放在算式栏里，用等号连起来。只有最后的数进结果栏，右对齐、加粗。
- 结果后面的比较（`≤ 655,360 B`、`≈ 7.969 MiB`）排在结果下面，用小字。
- 旁注排在这一行下面，用小号浅色字，左边和算式栏对齐。
- `title` 排在框的下方，位置和图说明一样。
- 同一页里所有算式块的标签栏宽度相同，所以各块算式栏的起点上下对齐。

## 最小例子

````markdown
```calc
title: KV 块的大小是怎么定的
MLA 一层一块 = 640 token × 1024 B（512 维 × 2 B） = 655,360 B
KDA 一层一份状态 = 36,864 B 卷积 + 524,288 B 递推 = 561,152 B ≤ 655,360 B
每块号 = 12 × (655,360 + 40,960) B = 8,355,840 B ≈ 7.969 MiB（每张卡）
折合每 token = 8,355,840 B ÷ 640 = 13,056 B
> 其中 MTP 层占 1,088 B
```
````

## 规则

### 1. title

- 写法：围栏的第一个非空行写 `title: 名字`，冒号用半角 `:` 或全角 `：` 都可以。
- 用途：`title` 是整组计算的名字，显示在框下方，写成一个短名词短语，例如「KV 块的大小是怎么定的」。
- 可以不写。不写就不显示标题，程序也不会拿第一行的标签拼一个标题出来。
- 只有第一行的 `title:` 会被认出来。写在其他行的 `title:` 按普通文字处理。

### 2. 一项一行

基本写法是 `标签 = 算式 = … = 结果`：

- 第一个等号左边是标签，最后一个等号右边是结果，中间每一段是一个中间步骤，数量不限。
- **等号两边都要有空格**，这样的 ` = ` 才算分隔。`a=b`、`TP=8` 这种不带空格的等号只是字面上的等号。
- 可以没有中间步骤，只写 `标签 = 结果`，例如 `42 层 = 17.72 GiB`。
- 标签和结果之间也可以用 `≈`、`≤`、`≥` 连接，见规则 15。

### 3. 标签可以带括号

标签可以带全角或半角括号，例如 `KDA 每层每请求的状态（TP=8 之后）`、`MLA 每 token 每层 (BF16)`。括号里的字属于标签。

### 4. 算式里的函数调用和括号

- 算式里可以写函数调用，也可以嵌套括号，例如 `ceil(561,152 / (128 × 1024))`、`min(128, max(a = 4, 8))`。
- 括号里的 ` = ` 不算分隔。能起这个作用的括号包括半角和全角圆括号、方括号 `[]`、花括号 `{}`。
- 括号必须配对。如果一个左括号没有配上，它后面的等号都不会被拆开。

### 5. 近似结果

如果最后一段写成 `算式 ≈ 数`，这个近似数就是结果，前面的算式变成中间步骤，结果前的符号显示成 `≈`。例如：

```
能存 = 3,855 × 640 ≈ 2.47 M token
```

如果结果本身已经是一个数，后面的 `≈ 数` 就只是换算，按规则 6 处理。例如 `= 8,355,840 B ≈ 7.969 MiB` 的结果是 8,355,840 B。

### 6. 结果后的比较

- 结果后面可以跟一个比较，写成「空格 + 比较号 + 空格 + 数」。
- 比较号可以用 `≤ ≥ ≈ ≠ < >` 中的任意一个，例如 `561,152 B ≤ 655,360 B`。
- 比较排在结果下面一行，用小字。它仍然算作算式的一部分，不属于旁注。

### 7. 结果后的说明

结果后面的解释性文字会成为这一行的旁注，排在这一行下面，有两种写法：

- 用全角逗号引出：`42 层 = 17.72 GiB，占主干 45 层权重的 88%`。
- 用全角括号包住：`每卡每层权重 = … = 432 MiB（int8）`。

说明会去掉打头的「，」或外层的「（）」后再显示。

说明从结果后面、括号外的第一个「（」或「，」开始算。所以 `151.25 MiB（BF16：16 位浮点，每个数 2 字节）` 里，括号内的逗号不会把说明再切开。

如果说明里要写 ` = `，要么把整段说明放进括号，要么改用规则 9 的旁注行，要么把等号转义成 `\=`（见规则 12）。

### 8. 结果只包括数和单位

结果栏只放「一个数 + 最多两个单位词」：

- 第一个单位词可以是任何词，例如 `块`、`GiB`、`个专家`。
- 第二个单位词必须是英文，例如 `640 个 token`、`2.47 M token`。
- 单位后面多出来的文字自动变成旁注。例如 `30.00 GiB 可用于 KV` 的结果是 `30.00 GiB`，旁注是「可用于 KV」。

这条规则是给旧块兜底用的。新写的块要把说明明确写出来：`30.00 GiB，可用于 KV`。

结果不是数的时候（形状、文字，例如 `[4, 4096]`、`TP8 内按元素相加`），这一项不加粗，也不单独占结果栏，算式栏会一直延伸到行尾。

### 9. 旁注行

以 `> `（大于号加空格）开头的一行，是挂在上一项下面的旁注。适合写较长的说明，或者写带等号的说明：

```
折合每 token = 8,355,840 B ÷ 640 = 13,056 B
> 其中 MTP 层占 1,088 B
```

同一项的几段说明会用「，」连起来，顺序是：规则 8 截出的文字、结果后的「，…」或「（…）」、旁注行。

### 10. 续行

以 `= ` 开头的一行接在上一项后面，上一项原来的结果会变成中间步骤。一条推导很长时，可以竖着写：

```
每块字节 = 12 × 655,360（MLA 主 cache）+ 12 × 40,960（索引器压缩 cache）
  = 8,355,840 B
```

### 11. 整行说明与分组

- 没有 ` = ` 的一行是整行说明，横跨四栏，用浅色字显示。
- 空行用来分组，会在两组之间留一段空隙。
- 框首和框尾的空行不显示。

### 12. 转义

在任意一个字符前加反斜杠 `\`，这个字符就按字面显示，不再有语法作用。常用的几种：

| 写法 | 作用 |
|---|---|
| `\=` | 两边带空格的等号不当分隔 |
| `\（`、`\，` | 结果后的括号或逗号不当旁注的开头 |
| `\：` | 标签里的冒号不当旧写法的分隔（见规则 13） |
| `\>` | 行首的 `>` 不当旁注行 |
| `\\` | 一个反斜杠本身 |

转义只在 ```calc 里生效。旧的 ```text 块是作者当代码写的，里面的反斜杠按原样显示。

### 13. 旧写法「标签：算式 = …」

旧写法仍然能认，处理方式如下：

- 标签里括号外有全角冒号「：」，并且冒号后面是一个算式（有前后带空格的运算符）时，冒号后面的部分算作第一步。例如 `D₁ 各约 20,000 个位置：ceil(20003 / 640) + 14 = 32 + 14 = 46 块`。
- 冒号在标签末尾时直接去掉，例如 `剩下： = …`。
- 冒号后面不是算式时，冒号属于标签本身，例如 `不开 KVPP：每卡每块 = L × b`。

新写的块一律用 `标签 = 算式`，不要用冒号。

### 14. 运算符与括注

- 前后都有空格的 `×`、`÷`、`+`、`−` 才算运算符，显示成浅色。前后带空格的 ASCII `*`、`/`、`-` 也算运算符。
- 不带空格的写法不算运算符，例如 `4×4`、`2/3`、`max-model-len`。
- 算式里的全角括号「（…）」是括注，用小一号的浅色字显示，例如 `1024 B（512 维 × 2 B）`。

减号优先用 `−`（U+2212），不要用 `-`，这样和连字符分得开。

### 15. 用 ≈ ≤ ≥ 连接标签和结果

`≈`、`≤`、`≥` 和 `=` 一样，可以把标签和结果连起来，前后同样要有空格。结果栏前面显示你写的那个符号，不会改成 `=`：

```
42 层 ≈ 55.1 MiB
每卡每次的 token ≤ 128
预算外的余量 ≥ 9.6 GiB（15%）
```

- 一行里括号外最靠前的 ` = `、` ≈ `、` ≤ `、` ≥ ` 是标签和后面部分的分界。
- 标签后用 `≈`、后面还是一个算式时，按规则 5 处理：`每条 ≈ 399 ÷ 32 × 640 ≈ 7,980 个位置` 的结果是 7,980 个位置，`399 ÷ 32 × 640` 是中间步骤。
- 结果后面仍可以跟比较（规则 6），例如 `42 层 ≈ 55.1 MiB ≤ 64 MiB`。
- 续行也可以用 `≈`、`≤`、`≥` 开头，效果和把这一段写在上一行末尾一样：

  ```
  每层合计 = 262,400 B + 524,288 B
    ≈ 0.75 MiB
  ```

- 标签后面接了 `≈`、`≤`、`≥`，后面就不要再用 `=` 串中间步骤：版式里标签和第一步之间不显示符号，那个 `≈` 会看不见。
- 中间步骤之间只用 `=` 连接。`≈` 只放在最后，写成「算式 ≈ 数」（规则 5）或「数 ≈ 换算」（规则 6）。
- `<`、`>`、`≠` 不是连接符，所以 `提示词 > 8192 − 48 就要切` 仍是整行说明。

## 改写旧块的对照

旧的 ```text 块满足下面的条件时，页面会自动把它排成算式块：

- 每一行都写成 `标签 = …`，或者以 `= ` 开头接在上一行后面；
- 各列靠连续空格对齐。

不满足这些条件的块仍然按代码块显示，要改写成 ```calc。改写时按下面几条做：

1. 每项一行，写成 `标签 = 算式 = 结果`，不再用空格对齐。
2. 标签后面不写冒号。
3. 说明用「，」或「（）」接在结果后面，或者改成 `> ` 旁注行。
4. 不是算式的句子单独占一行（规则 11）。
5. 给整组计算写一个 `title:`。

改写前（代码块，混着冒号、空格对齐和句子）：

```text
每卡每次最多 ceil(128 ÷ 8) = 16 个 token，TP8 共 16 × 8 = 128
判断用的是两台机器里较大的那个 token 数
```

改写后：

````markdown
```calc
title: 什么时候走 MC2
每卡每次最多 = ceil(128 ÷ 8) = 16 个 token
TP8 共 = 16 × 8 = 128 个 token
判断用的是两台机器里较大的那个 token 数
```
````
