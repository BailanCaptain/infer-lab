## 注意力在模型层中完成什么

[前馈网络](mlp-residual-norm.md)对各位置分别变换特征，注意力则引入上下文中的其他位置。它接收当前隐藏表示，生成与上下文相关的新表示，再交给该层的残差连接。

本页先展开**缩放点积注意力**这一基础计算。GLM-5.3-Flash 的稀疏 MLA 使用位置选择与压缩表示，KDA 则更新递推状态；这些结构共享部分术语，但不能统一画成完整的 `QKᵀ → softmax → V`。两类组件在[主模型图](glm-5-3-flash.md)中分别展开。[C4]

## Q、K、V 的区别在于参与哪一步计算

对于最基本的单头自注意力，设输入矩阵为 `X`，每行是一个位置的隐藏向量。通过三个学习得到的投影可写为 `Q = XW_Q`、`K = XW_K`、`V = XW_V`，三组参数分别决定输入如何变换为查询、键和值。[S1]

| 表示 | 作用 | 与其他表示的关系 |
|---|---|---|
| Q（Query，查询） | 为当前输出位置计算注意力分数 | 与可访问位置的 K 做点积 |
| K（Key，键） | 参与位置匹配 | 与 Q 有相同的点积维度 |
| V（Value，值） | 提供被加权汇合的内容 | 向量宽度可以与 Q/K 不同 |

K 与 V 分开，使评分空间和输出内容空间可以采用不同投影。每层根据自己的输入与参数产生表示；一个位置经过前面的层后，隐藏向量已经包含上下文，这些上下文信息也会参与下一层 Q/K/V 的形成。

## 一个查询怎样得到输出

对查询位置 `i` 与键位置 `j`，设 Q/K 的头维度为 `d_k`。基础计算为：[S1]

```text
s_ij = (q_i · k_j) / sqrt(d_k) + m_ij
a_ij = exp(s_ij) / Σ_l exp(s_il)
o_i  = Σ_j a_ij v_j
```

`m_ij` 是掩码项：允许的位置取 0，被屏蔽的位置取负无穷。softmax 沿键位置归一化，得到这一查询的组合权重。它与末尾在词表上选择下一个 token 的 softmax 作用对象不同。

下图取查询位置 2，用四个位置展示计算。假设掩码后的分数为 `[ln 2, 0, 0, −∞]`，权重就是 `[0.5, 0.25, 0.25, 0]`；这些是手算数据，并非模型运行结果。[A][D]


若前三个 V 分别是 `[2, 0]`、`[0, 2]`、`[2, 2]`，则输出为 `0.5×[2,0] + 0.25×[0,2] + 0.25×[2,2] = [1.5,1]`。[D] 注意力权重控制各向量的贡献，输出仍是一个向量。

缩放因子用于控制点积随维度增长的数值尺度。公式中的 softmax 可等价地先减去行最大值再计算指数，以避免较大正数直接取指数。[D] 图描述数学关系；中间结果是否写入显存，由具体内核实现决定。

## 因果掩码限定每个位置能访问的历史

自回归生成要求位置 `i` 的表示只能使用位置 `0…i` 的输入，之后据此预测位置 `i+1`。因果掩码按位置执行这一限制；它也适用于已经一次性送入模型的完整提示词。[S1]

```wiki-diagram
file: attention-causal
```

沿用[单请求页](one-request.md)的四位置教学输入：Prefill 同时计算位置 0–3，最后位置可以访问四个输入；其他行仍各有自己的可见范围。随后若把生成的 token 放到位置 4，普通 Decode 只新增一个查询位置，读取此前保存的历史，并加入位置 4 自己的数据。[A]

对于普通全注意力，后续查询需要此前各位置的 K/V；将它们保存在 [KV Cache](kv-cache.md) 中，可以避免重复计算这些历史表示。此前位置的 Q 已完成自己的输出计算，后续位置使用各自的新 Q。[D] GLM 两类注意力所保存的对象则分别由压缩表示和递推状态决定。

这解释了 Prefill 与 Decode 的一个关键区别：**本轮查询位置数**和**可访问历史长度**是两个维度。对于普通单头点积注意力，可写为 Q `[T,d_k]`、K `[S,d_k]`、V `[S,d_v]`，输出 `[T,d_v]`；`T` 是本轮查询数，`S` 是包含本轮数据在内的键序列长度。多个请求合批时，每个查询仍只能访问所属请求允许的历史，映射见[并发请求](concurrent-requests.md)。

## 多个头产生不同的汇合结果

单头形成一组位置权重和一个汇合结果。多头允许不同学习投影形成不同的评分与特征组合，再统一投影；每个头并不保证对应某种可命名的语义。多头注意力同时构造多组查询，每组分别计算注意力输出，再拼接并投影回隐藏宽度。下图用四个头展示汇合关系，数量仅为示意。[S1][A]

各头形成的权重分布由输入与训练得到的参数决定。Q 头数、KV 头数与每头宽度是分别配置的结构量；[GQA](gqa.md)专门讨论多个 Q 头共享 K/V 的结构。

GLM 的稀疏 MLA 分支配置了 64 个查询头，Q/K 的逻辑头宽度为 256，V 的逻辑头宽度也是 256；输出投影将 `64×256` 的多头结果映射回 4096 维。[S2][C3] 这里的“逻辑头”描述计算分解，**不代表缓存中保存了 64 份完整 K/V**：其历史以压缩表示组织，详情在 [MLA](mla.md) 中展开。

## 从基础公式回到 GLM 的两类注意力

| 结构 | 历史如何参与 | 基础公式的适用范围 |
|---|---|---|
| 通用因果全注意力 | 对所有允许位置评分并汇合 | 本页完整展开的基础形式 |
| GLM 的稀疏 MLA | 索引器选择可访问历史中的候选，再执行注意力 | 需要同时考虑稀疏候选与压缩投影，不能据查询头数推算缓存 |
| GLM 的 KDA | 由当前输入与递推状态共同产生输出 | 虽也有 Q/K/V 投影，后续计算不是逐历史位置的 softmax |

固定实现按层型选择 KDA 或 MLA；KDA 路径也显式计算 Q/K/V，并生成控制状态更新的其他量。[C4][C5] 因此，阅读代码时仅搜索 `q_proj` 或 `k_proj`，不足以判断注意力机制。

本页的 GLM 数字依据[固定配置与 Ascend 专用源码](../sources/glm-5-3-flash-baseline.md)。稀疏候选、KDA 递推和缓存布局属于各自专题；这里未展开设备分片，也没有内核耗时实测。
