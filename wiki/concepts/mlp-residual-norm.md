## 注意力看完了，收进来的东西谁来消化

[层与隐藏向量](layers-and-hidden.md)那一页鸟瞰过：一层里有两段，先「互相看」，再「各算各的」。[注意力](attention-qkv.md)讲完了前一段——每个 token 从前面的 token 那里收了一圈信息，混进了自己那串数字里。

可是光收进来没有用。就像开会：听了一圈别人的发言，回到座位上总得自己想一想，把听来的东西和自己原来知道的捏合成新的判断。层里的另一半干的就是这件事。

这一页把另一半讲完。除了注意力，一层里还有三样东西：MLP、残差、归一化。名字听着唬人，每样用几句白话就能说明白，最后把一层的完整顺序拼出来。

## MLP：换宽度、筛一遍、再变回来

MLP 是注意力之后逐个加工 token 的前馈网络。可以先按「换到中间宽度 → 非线性加工 → 变回原宽度」理解：

1. **换宽度**：用[矩阵乘](matmul-and-weights.md)变到中间宽度。普通大 MLP 常会扩宽，但本例单个专家反而压窄。
2. **筛一遍**：中间数字过一个「开关」，没用的部分被关小，有用的部分留下来。这一步的术语叫「激活」，知道有这么一道关卡就够了，本页不展开它里面的算法。
3. **变回去**：再用矩阵乘变回原来的长度。进来多长，出去还是多长。

本例用的是带门控的 MLP：输入先走两片权重，一支经过激活后与另一支逐项相乘，再走第三片权重输出。因此数学上有三片权重、三次线性变换；实现可以合并前两支的计算，不能笼统说所有 MLP 都只有两片权重。

最要紧的是这一句：**MLP 这一段，每个 token 各算各的，互相不看**。这和注意力正好互补——注意力管交流，MLP 管消化。一层走完，每个 token 既跟别人交流过一次，也自己消化过一次。

在[贯穿例子](one-request.md)的模型里，这一段被换成了一组[专家（MoE）](moe.md)：每个专家就是一个小 MLP，每个 token 只挑其中几个来给自己消化。怎么挑在那一页讲；读本页时，把「一组专家」当成「MLP 坐的那个位置」看就行。

## 残差：每层交出来的是修改量，不是新答案

[层与隐藏向量](layers-and-hidden.md)说过，那串数字「每过一层被改一次」。现在可以把「改」字说准了：注意力和 MLP 这两段，算出来的结果都**不直接当作新的那串数字**，而是当作一份「修改量」，**加回**原来那串数字上。输入通过旁路参与加法，输出是「输入 + 这一段的计算结果」，结果不要求很小。这个做法叫残差。

残差给信息和训练时的梯度提供了更直接的传播路径。如果某段输出接近零，输入可以近似原样通过；但它不保证原始信息永远不会丢失，也不是「每层只能小改」。图里的旁路表示加法关系，不表示保存了一份永远不变的原稿。

## 归一化：每段开算之前，先把数字缩到差不多大小

一层里还剩最后一个小零件。两段计算各自开算之前，都要先把那串数字**整体缩放到差不多的大小**——一层层加下来，数字难免越滚越大或越缩越小，不先缩一下，越往后算越偏。这一步叫归一化，这个模型用的做法叫 RMSNorm。

它在一层里出现两处：注意力开算前一次，MLP（或专家）开算前一次。都是同一个意思：先把料理平整了，再下刀。

顺带一句：你可能在别处见过 LayerNorm 这个词。那是归一化的**另一种做法**，不是 RMSNorm 的另一个名字，两者不能混着叫。差别在哪本页不展开。

## 拼出来：一层的完整顺序

零件齐了，按顺序摆一遍。一串数字进到一层里，走的是：

**归一化 → 注意力 → 加回去 → 归一化 → MLP（或专家）→ 加回去**，然后出层，交给下一层。

## 在贯穿例子里，这些数具体多大

落到那条请求上。每个 token 的那串数字是 2048 个（隐藏维度 2048），整层进 2048 出 2048——残差是加法、归一化是缩放，都不改长度。

MoE 的每个专家，把 2048 长的串变换到 **512** 长的中间串，筛一遍，再变回 2048。注意一个反差：普通大 MLP 常先扩宽，可这个模型的**单个专家反而是先压窄**——2048 进去，中间只有 512。这不矛盾，正是「很多小专家代替一个大 MLP」的特点：单个专家很窄，但每层有 256 个专家，每个 token 同时用上挑中的 8 个再加 1 个所有 token 共用的共享专家，几份小加工合在一起顶一份大的。

至于这些又窄又多的专家怎么摊到两颗 NPU 上，是[专家并行](expert-parallel.md)的事了。

### 版本差异

这里只核过 vLLM v0.23.0（配套 Ascend releases/v0.23.0）。其他模型可能使用不同激活、归一化位置和前馈结构；不能从本例推出所有 MLP 都有相同矩阵数量。

### 源码位置

- 配置的 `hidden_size = 2048`、`moe_intermediate_size = 512`、`shared_expert_intermediate_size = 512` 给出本例宽度 [S1]。
- `Qwen2MoeMLP`（在 Qwen3Next 中复用）将 gate/up 两支合并为 `gate_up_proj`，经 `SiluAndMul` 后用 `down_proj` 还原宽度 [C1]。
- Decoder 的两次 norm、注意力和 MLP 顺序见 `forward` [C2]；残差由融合归一化接口携带，逻辑加法不一定各对应一个独立算子。
- 本例使用 `Qwen3_5RMSNorm`，并非 LayerNorm；MoE 分支与两处归一化的构造见 [C3]。
